PRIVACY · WEBSITE

隐私政策

本说明介绍本网站的浏览器偏好设置、本地问答助手与外部链接，帮助区分仅浏览页面和您主动向门店或第三方提供信息的情况。

只浏览网站需要提交个人资料吗？

不需要主动填写姓名、护照或付款资料。本网站以静态内容介绍租车服务，没有站内账号、付款或预约表单。但访问网页可能涉及托管平台所处理的 IP、浏览器等技术数据，因此不能将“不填写表单”等同于“绝无技术数据处理”。

为记住用户选择，您的浏览器可在本地存储界面语言及浅色／深色主题偏好。您可通过浏览器设置清除此类本地数据。

本地租车助手如何使用您的问题？

网站当前的本地问答助手在您的浏览器中读取本站公开的问答索引；不连接外部人工智能 API，也不通过此助手自动提交租赁订单。聊天内容显示在当前网页，不等于已向门店发送私人消息。

助手的答案不能实时核实库存、确定法律资格或确认预订。如您改用电话、Zalo 或 WhatsApp 联系，主动传送的信息将涉及相关通信渠道与接收方。

网站访问时第三方可能处理什么技术数据？

本网站通过 GitHub Pages 托管。托管商及浏览器访问所连接的外部平台可能按各自政策处理 IP 地址、设备信息、请求日志或其他必要技术数据。本网站不对第三方的处理范围、保留时长作未经核实的保证，请参阅其最新官方隐私政策。

通过电话、Zalo、WhatsApp 或地图联系后会怎样？

进入外部应用后，您主动发送的消息可能由该服务及接收方处理。普通询价建议先仅提供租车日期、车型与联系方式；除非确有合法需要且已了解用途和处理方式，否则不要发送护照照片、银行卡号或其他非必要敏感信息。

请查看相应第三方服务自己的隐私说明。本网站无法控制其 Cookie、访问记录或账户设置。
